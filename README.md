# Arrecife Marketing Group · sitio web

Sitio de [arrecifemkt.com.mx](https://arrecifemkt.com.mx): React + Vite + Tailwind, publicado en GitHub Pages con dominio propio.

## Trabajar en local

```bash
npm install
npm run dev
```

## Publicar

```bash
npm run deploy
```

Construye `dist/` y la sube a la rama `gh-pages`. El archivo `public/CNAME` mantiene el dominio.
